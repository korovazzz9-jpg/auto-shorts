# Лика в Instagram и TikTok — по шагам

Те же 42 ролика, что идут на YouTube (@smeshno_shorts), в том же порядке (`CHANNEL_PACK.md`), 2 в день.
Выкладывает `src/publish_lika_social.py`, запускает Планировщик заданий Windows в 16:00 и 23:00 по Вьетнаму
(= 12:00 и 19:00 МСК). Компьютер в это время должен быть включён (или выйти из сна — задание его будит).
Пароли и коды вводишь только ты; скрипт работает по токенам из `.env`.

---

## A. Instagram

Instagram даёт выкладывать по API только «профессиональным» аккаунтам, привязанным к странице Facebook.
У фактов (@a30secfacts) это уже настроено — используем тот же Business-кабинет и то же приложение Meta.

1. **Аккаунт.** Приложение Instagram → профиль → имя вверху → «Добавить аккаунт» → «Создать новый».
   Имя — например `smeshno_shorts` (как на YouTube), аватар — тот же, что у канала.
   Описание: «Сценки с Ликой 😏 Новые каждый день. Персонажи созданы ИИ».
2. **Профессиональный аккаунт.** Настройки → «Тип аккаунта и инструменты» → «Переключиться на профессиональный» →
   «Автор» → категория «Комик» / «Развлечения».
3. **Страница Facebook.** facebook.com/pages/create → название «Юмор шортс Humor Shorts», категория «Комедия».
   Затем на странице: Настройки → «Связанные аккаунты» → Instagram → «Подключить» → войти в новый аккаунт.
4. **Добавить в Business-кабинет.** business.facebook.com → Настройки → «Аккаунты»:
   - «Страницы» → «Добавить» → «Добавить существующую» → новая страница;
   - «Аккаунты Instagram» → «Добавить» → новый аккаунт.
5. **Доступ системному пользователю.** Там же «Пользователи» → «Системные пользователи» → тот же, что для фактов →
   «Назначить ресурсы»: новая страница и новый Instagram — полный доступ.
6. **Токен.** У того же системного пользователя → «Создать токен» → то же приложение → срок «Никогда» →
   разрешения: `instagram_basic`, `instagram_content_publish`, `pages_show_list`, `pages_read_engagement`,
   `business_management`. Скопируй токен.
7. **ID аккаунта.** В браузере (подставь токен):
   `https://graph.facebook.com/v21.0/me/accounts?fields=name,instagram_business_account{id,username}&access_token=ТОКЕН`
   Нужен `instagram_business_account.id` у страницы «Юмор шортс».
8. **В `.env`** (C:\work\auto-shorts\.env) дописать:
   ```
   IG_ACCESS_TOKEN_HUMOR=токен
   IG_USER_ID_HUMOR=id
   IG_USERNAME_HUMOR=smeshno_shorts
   ```
9. **Проверка:** `py src/publish_lika_social.py --platform ig --dry` — покажет следующий ролик и подпись.

## B. TikTok

1. **Аккаунт.** Приложение TikTok → профиль → имя вверху → «Добавить аккаунт» → регистрация (лучше другая почта).
   Имя `smeshno_shorts`, аватар и описание как в Instagram. В настройках → «Аккаунт» → можно оставить личный.
2. **Приложение разработчика.** developers.tiktok.com → «Manage apps» → то же приложение, что для фактов.
   В «Products» должен быть **Content Posting API**, в «Scopes» — `video.upload` (и `video.publish`).
   Приложение ещё не прошло аудит — тогда: «Sandbox» → «Target users» → добавить новый аккаунт Лики.
3. **Токен.** В папке auto-shorts:
   ```
   py src/get_tiktok_token.py
   ```
   Откроется браузер → войди В АККАУНТ ЛИКИ → разреши → скопируй адрес страницы, куда перекинет, вставь в окно.
   Потом:
   ```
   py src/exchange_tiktok_token.py
   ```
   Из вывода `refresh_token` → в `.env`: `TIKTOK_REFRESH_TOKEN_HUMOR=...`
   (`TIKTOK_CLIENT_SECRET` там уже есть). Токен доступа скрипт обновляет сам каждый запуск.
4. **Как будет выкладываться.** Пока приложение без аудита, TikTok принимает ролики только «в черновики»:
   приходит уведомление в приложении TikTok → открыть → вставить подпись из `stats\humor\tiktok_captions.txt` →
   включить метку «Контент создан ИИ» → «Опубликовать». Это ~30 секунд на ролик.
   После аудита приложения: в `.env` `TIKTOK_MODE_HUMOR=direct` — ролики пойдут сразу публично с подписью.
   **Запасной путь, если API откажет:** tiktok.com/tiktokstudio/upload с компьютера — там есть «Запланировать»
   до 10 дней вперёд, ролики лежат в `video_gen\ui\_cp77_series\girl01\final`, подписи — `--dry`.

## C. Запуск по расписанию

1. Проверить по одному ролику вручную:
   ```
   py src/publish_lika_social.py --platform ig --yes
   py src/publish_lika_social.py --platform tiktok --yes
   ```
2. Поставить расписание (один раз):
   ```
   powershell -ExecutionPolicy Bypass -File scripts\setup_lika_social.ps1
   ```
   Только Instagram: добавить `-Platforms ig`. Снять: `-Remove`.
3. Что выложено — `stats\humor\social.csv`, журналы — `stats\humor\social_ig.log`, `social_tiktok.log`.
   Повторный запуск не дублирует: каждый раз берётся следующий невыложенный ролик.

Ограничения: Instagram и TikTok по API отложенную публикацию не дают — публикуют в момент запуска, поэтому
компьютер должен работать. При ошибке ролик не отмечается выложенным и уйдёт в следующий запуск.
